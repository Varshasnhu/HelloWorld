# Python Learning Path: Basics to Intermediate

Welcome to your Python learning journey! This guide will take you from complete beginner to intermediate level.

---

## **PART 1: BASICS (Week 1-2)**

### 1.1 Variables & Data Types
- **Strings**: Text data
- **Integers**: Whole numbers
- **Floats**: Decimal numbers
- **Booleans**: True/False

### 1.2 Input & Output
- `print()` - Display output
- `input()` - Get user input

### 1.3 Basic Operations
- Arithmetic: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- String concatenation
- Type conversion

### 1.4 Comments
- Single line: `#`
- Multi-line: `""" """`

---

## **PART 2: CONTROL FLOW (Week 3)**

### 2.1 Conditional Statements
- `if`, `elif`, `else`
- Comparison operators: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Logical operators: `and`, `or`, `not`

### 2.2 Loops
- `for` loops
- `while` loops
- `break` and `continue`

---

## **PART 3: DATA STRUCTURES (Week 4)**

### 3.1 Lists
- Creating, accessing, modifying
- List methods: `append()`, `remove()`, `pop()`, `sort()`
- List slicing

### 3.2 Dictionaries
- Key-value pairs
- Accessing values
- Dictionary methods

### 3.3 Tuples
- Immutable lists
- When to use tuples

### 3.4 Sets
- Unique elements
- Set operations

---

## **PART 4: FUNCTIONS (Week 5)**

### 4.1 Defining Functions
- Function syntax
- Parameters & arguments
- Return values

### 4.2 Scope
- Local vs Global variables
- Variable lifetime

### 4.3 Advanced Functions
- Default parameters
- *args and **kwargs
- Lambda functions

---

## **PART 5: INTERMEDIATE CONCEPTS (Week 6-8)**

### 5.1 File Handling
- Reading files
- Writing files
- Working with different file formats

### 5.2 Error Handling
- Try-Except blocks
- Multiple exceptions
- Finally clause

### 5.3 Modules & Libraries
- Importing modules
- Using built-in modules
- Installing external packages (pip)

### 5.4 Object-Oriented Programming (OOP)
- Classes and Objects
- Attributes and Methods
- Inheritance
- Polymorphism
- Encapsulation

### 5.5 List Comprehensions
- Concise list creation
- Dictionary comprehensions

### 5.6 Decorators (Introduction)
- Function decorators
- Using existing decorators
